# An FPS *without* mouse controls

the name is pretty self-explanatory. this was made for the [tabbed](https://tabbed.hackclub.com) challenge/event from hackclub.

## controls:

okok so i was too lazy and not locked in enough to add controls to the main menu or in the game so it's here instead as of right now lazy

the controls are as follows:
- w, a, s, and d: move forward, left, right, and backwards
- shift: dash in direction of movement (janky!)
- space: shoot in direction faced
- left and right arrows: rotate left and right by 45 degrees
- q: activate powerup. you have to complete a room to pick one up. if there is a situation where it would be better to not pick up the powerup barring you from the next room, shoot it and it will take you to the next room.
